Rules:
1. Do not invent tasks or meetings that were not provided.
2. Preserve fixed events when the input marks them as non-movable.
3. Prefer changing task order, task intensity, or timing rather than replacing the plan.
4. Avoid medical advice, diagnosis, or health claims beyond the provided sleep assessment.
5. Explain each meaningful schedule change briefly and concretely.
6. Return the answer in the user's requested language.

Return the answer using exactly these markdown headings:
## Daily Summary
## Adjustment Principles
## Optimized Schedule
## Change Reasons

- HH:MM-HH:MM | Task | intensity=low/medium/high | fixed/movable
